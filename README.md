# 🌀 Dadabot: Дадаистский Телеграм-Бот

**Dadabot** — это абсурдный, квантово-хаотичный бот, созданный с художественной и экспериментальной целью. Он разрушает шаблоны общения, генерирует бессмысленные мысли, псевдонаучные графики и сюрреалистические изображения, а также рассылает гороскопы из антиматерии.

## 🚀 Возможности

- `🧠` Генерация квантовых мыслей на основе dada-фраз
- `📷` Получение случайных артефактов с NASA и Wikimedia Commons
- `🧪` Генерация несуществующих химических соединений (органика и неорганика)
- `🔮` Квантовые гороскопы с формулой для избегания
- `💣` Метафорический взрыв
- `🎭` Поддержка inline-режима с бессмысленным контентом
- `👻` Анимации, уровни банальности и квантовые коллапсы
- `📨` Ежедневная рассылка предсказаний подписчикам

## ⚙️ Установка

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

> Обязательно: `aiohttp`, `aiogram`, `python-dotenv`, `pillow`, `pydantic` и `apscheduler`

2. Создайте файл `.env`:

```env
BOT_TOKEN=ваш_токен_бота
ADMIN_IDS=12345678,98765432
NASA_API_KEY=ваш_ключ_от_nasa_api
IMGUR_CLIENT_ID=опционально
```

3. Запуск:

```bash
python dadabot.py
```

## 📁 Структура

- `config/` — настройки и переменные окружения
- `core/` — инициализация бота
- `handlers/` — команды и текстовые реакции
- `generators/` — логика генерации: текст, картинки, химия, графики
- `states/` — управление пользовательским состоянием
- `utils/` — вспомогательные функции и логика рассылки
